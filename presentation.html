01 · PROBLEM & MOTIVATION

專案背景與現有工具的三大痛點

從「真人參考照片」到「底層骨骼結構理解」的斷層

1. 照片遮擋與透視盲區
  • 模特兒穿著寬鬆衣物、裙擺或大衣時，骨盆傾角 (Pelvic Tilt) 與髖關節位置完全被遮蔽。
  • 側身回眸、仰俯視或大幅度扭腰時，初學者難以判斷胸廓籠與骨盆的相對扭轉角度。
2. 傳統 3D 人偶操作繁瑣
  • 使用 CSP 或 Blender 手動擺出照片中的姿勢，往往需要調整數十個旋轉軸，耗時費力。
  • 一般素體人偶僅呈現外表面，無法觀察內部的脊椎 S 曲線、肩胛骨滑動與尺橈骨交叉。
3. 單一視覺 AI 容易誤判
  • 傳統骨架偵測（OpenPose / MediaPipe）僅輸出「火柴人連線」，無真實骨骼幾何體積。
  • 缺乏全局語意理解，經常發生「正背身顛倒」、「男女骨架誤判」、「跪姿誤判為半身裁切照」。
🎯 我們的專案目標
打造一個免安裝、純瀏覽器運行的 Web 3D 系統：使用者只需拖曳上傳一張照片，系統即可在 1.5 秒內結合高階 AI 語意理解與解剖運動學，自動重建出結構精確、比例合宜且可手動微調的 3D 解剖骨骼模型。

02 · SYSTEM ARCHITECTURE

核心創新：雙階段 AI 混合管線 (Two-Stage Hybrid Pipeline)

結合 VLM 高階全局語意理解（Stage 1）與 Holistic 局部幾何座標定位（Stage 2）的互補優勢

Stage 1：Gemini 3.5 視覺語意預判
visionClassifier.js (512px 單磚極速推論)
  • 性別骨架：female / male
  • 面向模式：正面 / 180°純背身 / 背身回眸
  • 空間轉角：胸廓 Yaw 角、頭部 Yaw 角
  • 構圖與姿態：isKneeling (跪坐)、isLegsTruncated (半身照)、頭身比 (6.5~8.5)
  • 雙手手勢分類：握拳、指人、YA、比讚、OK、張開、放鬆
➔
Stage 2：Holistic 節點 + 幾何防呆
poseDetector.js (多模態融合與防呆校驗)
  • 全身 33 節點 + 雙手 42 節點 2D/3D 座標提取
  • 語意先驗注入：鎖定正背身座標翻轉與男女骨骼形態
  • 2D 幾何防呆守衛：當五官清晰且雙肩展開時，自動攔截誤判的 180° 背身，修正為側身模式
  • 前後交叉步 (Tandem Stride) 雙腿重疊深度分離解算
➔
Stage 3：解剖運動學解算器
kinematicSolver.js & anatomy.js
  • 脊椎 S 曲線分配：骨盆傾角 ➔ 腰椎代償側彎 ➔ 胸廓歐拉角連動
  • 四肢球窩與樞紐關節解算：大臂三軸旋轉、尺橈骨翻轉、髖膝踝生理極限約束
  • 混合手部驅動：近景 21 指節逐指追蹤 + 遠景 AI 手勢預設自動切換
🛡️ 高可用性容錯設計 (Graceful Fallback)：內建 HTTP 503/429 自動退避重試（450ms）；若無網路或額度耗盡，自動無縫切換至本地 Holistic 幾何視覺預判引擎，確保系統 100% 可用。

03 · ANATOMICAL ENGINEERING

程序化 3D 藝用解剖骨骼系統 (`anatomy.js`)

以 Three.js 參數化幾何建構全身骨骼，實現真實解剖結構連動與性別二態性變形

1. 中軸骨骼：頭骨、24 節脊椎與胸廓肋籠
  • 分節可動脊椎：包含 7 節頸椎 (C1-C7)、12 節胸椎 (T1-T12)、5 節腰椎 (L1-L5) 與薦尾骨，忠實呈現人體側面生理彎曲（頸曲、胸曲、腰曲）。
  • 立體胸廓籠 (Ribcage)：12 對肋骨（真肋、假肋、浮肋）透過肋軟骨連接胸骨柄與劍突，提供繪師判斷軀幹空間朝向的核心體塊。
2. 上肢亮點：尺骨與橈骨「旋前/旋後」剪刀交叉
  • 一般 3D 模型僅將前臂做單一圓柱扭轉；本系統獨立建構尺骨 (Ulna) 與橈骨 (Radius)。
  • 當手掌旋前（Pronation，掌心朝後/下）時，橈骨遠端會真實跨越尺骨形成 X 型剪刀交叉；旋後（Supination）時恢復平行，手掌與 21 節指骨同步旋動。
3. 性別骨骼二態性 (Skeletal Dimorphism)
  • 女性骨骼形態 (♀)：纖細長骨、較小巧的胸廓籠、寬圓展開的髂嵴與較大恥骨弓角，胸骨位置隨胸廓深度自動同步貼合。
  • 男性骨骼形態 (♂)：粗壯長骨、寬闊肩膀與厚實胸腔、高窄直立的骨盆結構。
4. 下肢與足弓系統：大轉子、髕骨與地面吸附
  • 髖臼精準承接股骨頭，向外延伸出決定臀部最寬體表點的股骨大轉子 (Greater Trochanter)。
  • 包含膝關節髕骨、脛骨前脊（迎面骨）、腓骨、內外踝、距骨、跟骨結節與蹠趾骨，並支援動態最低點地面自動吸附 (Auto Ground Snap)。

04 · CHALLENGES & SOLUTIONS

實戰測試克服的五大關鍵技術挑戰

針對複雜攝影視角、服裝遮擋與極限肢體動作的演算法優化成果

實際遇到的影像難題 問題成因分析 (Root Cause) 我們的解決方案 (Engineering Solution)
1. 側身 / 背身回眸誤判 單純看臉部節點會把「背身回眸」當成正面；或因單側手臂遮擋把「90° 側身」誤判為 180° 純背身。 由 Gemini 預判 stanceMode，並加入 2D 臉部可見度 + 雙肩展開度幾何守衛，精準區分正面、側身、背身回眸與純背身。
2. 跪姿被誤判為「半身裁切照」 跪地時大腿與小腿摺疊，腳踝 Y 座標接近臀部，觸發「半身裁切鎖定標準站姿」保護機制。 結合 AI isKneeling 標記強制解除裁切鎖定、改以展開大腿+小腿骨骼總長計算頭身比，並解鎖深跪髖屈曲極限（-120°）。
3. 單腿後勾與前後交叉步失真 單腳向後勾起時僅單側小腿縮短；或前後交叉站立時雙腿在 2D 畫面 X 軸重疊。 將裁切判定改為雙小腿同時觸底 (&&)，並建立 Tandem Stride 雙腿重疊深度分離算法與 3D 畢氏定理膝屈曲還原。
4. 過頂舉手手腕交叉 & 遠景握拳 芭蕾過頂拱手時左右手腕目標點跨越中線；全身照手部僅佔 20px 時 Holistic 無法辨識握拳。 修正拱手目標座標極性（±2.15）；並由 Gemini 辨識 7 種手勢，在遠景自動覆寫模糊的 21 指節追蹤。
5. 雲端模型延遲與高解析度成本 上傳超過 512px 圖片會觸發 VLM 4 磚切割，Token 暴增 4 倍且容易遇到伺服器 503 尖峰擁塞。 固定縮圖長邊為 512px 黃金單磚解析度（僅 ~258 tokens），並實作 450ms 自動重試 + 本地端無縫降級。

05 · UI / UX & POSE TUNING

三欄式互動工作區與「部位分類折疊式」微調系統

將全身 34 項解剖自由度整理為直覺的隱藏式折疊清單，兼顧畫面清爽與專業控制力

🖼️ 左欄：參考圖與 2D 特徵區
  • 支援拖曳或點擊上傳任意人物參考照片。
  • 顯示骨架特徵線：在原圖疊加 MediaPipe 偵測之軀幹中軸、四肢連線與 21 手部節點，方便對照檢查。
  • 提供左右鏡像翻轉與正/背身一鍵翻轉快捷鍵。
🦴 中欄：360° 3D 骨骼互動視窗
  • 支援滑鼠左鍵 360° 環繞旋轉、右鍵平移、滾輪縮放。
  • 頂部提供正視、側視、後視、俯視四種標準正交/透視相機視角一鍵切換。
  • 底部懸浮膠囊即時顯示 Gemini AI / Holistic 診斷摘要（頭身比、性別、面向模式與手部追蹤狀態）。
🎛️ 右欄：4 大區塊與折疊清單
  • 1. 輸入人體參考圖：快速上傳區。
  • 2. 骨骼結構顯示：頭骨、胸廓、鎖骨肩胛、肱骨、尺橈骨、手部、骨盆、股骨、脛腓骨、足部 10 項獨立開關。
  • 3. 姿態微調：6 大身體部位折疊清單（共 34 項滑桿與手勢選單）。
  • 4. 其他（進階）：性別骨骼、頭身比、面向模式、地面自動吸附與參考網格。

06 · TECH STACK & PERFORMANCE

系統技術棧與執行效能指標

純前端輕量化架構，兼具雲端大模型的語意智慧與本地端 WebGL 的即時流暢度

💻 核心技術模組分工
  • index.html / style.css：響應式三欄暗色 UI 與原生 HTML5 <details> 折疊互動介面。
  • visionClassifier.js：第一階段 Gemini 3.5 Flash-Lite 視覺預判、512px 縮圖壓縮與自動重試/降級管理。
  • poseDetector.js：第二階段 MediaPipe Holistic 節點提取、語意融合與 2D/3D 幾何防呆驗證。
  • kinematicSolver.js：三維向量逆向運動學解算器（脊椎曲率、四肢歐拉角、手部 21 指節與手勢狀態機）。
  • anatomy.js / app.js：Three.js 程序化解剖骨骼建模、相機控制與雙向 UI 狀態同步。
⚡ 系統效能與成本指標
  • 影像預處理解析度：512 × 512 px 以內（JPEG 0.82 壓縮，剛好落入 Gemini 單一影像圖磚）。
  • 單次辨識 Token 消耗：僅約 258 Image Tokens + 120 JSON Tokens，成本趨近於零（每千次辨識不到 $0.05 美元）。
  • 端到端姿態還原延遲：約 0.8 秒 ~ 1.5 秒（含雲端語意預判 + 本地端 3D 骨骼解算）。
  • 3D 視窗渲染幀率：60 FPS 即時互動旋轉與滑桿無延遲微調。

07 · CONCLUSION & FUTURE WORK

專案總結與未來擴充展望

從「AI 姿態辨識」邁向「全方位 3D 藝用解剖數位教學平台」

🏆 專案核心成果總結
  • 架構突破：首創「Gemini VLM 語意預判 + MediaPipe 幾何節點 + 解剖運動學解算」混合管線，大幅降低背身、側身、跪姿與男女骨架誤判率。
  • 解剖專業度：忠實還原 24 節脊椎、胸廓籠、尺橈骨旋前/旋後剪刀交叉與男女二態性骨盆，超越一般火柴人骨架工具。
  • 極佳易用性：內建 API Key 開箱即用、提供 6 大部位折疊式微調清單與離線自動降級保護。
🚀 未來擴充方向 (Future Roadmap)
  • 1. 藝用表層肌群切換 (Ecorché Muscle Layer)：加入胸鎖乳突肌、胸大肌、三角肌、腹直肌與闊背肌的半透明疊加顯示。

  • 3. 多人互動與透視相機擬合：支援雙人對打/擁抱骨架還原，並自動擬合照片的廣角/長焦相機焦段 (FOV)。
