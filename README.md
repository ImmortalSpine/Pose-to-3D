# AnatoPose 3D (Pose-to-3D)
> 專為畫家與繪師打造的人體姿態 3D 藝用解剖骨架還原系統

![AnatoPose 3D](https://img.shields.io/badge/Status-Prototype%20MVP-orange)
![Three.js](https://img.shields.io/badge/3D-Three.js-black)
![MediaPipe](https://img.shields.io/badge/AI-MediaPipe%20Pose-blue)

AnatoPose 3D 是一個幫助繪師在參考照片時，自動識別模特兒動作並在 3D 空間中精準還原人體骨架結構的輔助創作工具。不同於一般粗糙的火柴人姿態估計，本系統嚴格遵循古典藝用解剖學與生物運動學的自然約束，為創作者提供 360° 可自由旋轉檢視、部位可獨立拆分觀察的立體骨架。

---

## 🌟 目前已實現功能 (Current Features)

### 1. 完整軀幹與骨盆解剖骨骼系統
* **脊椎系統 (Spine Column)**：
  * **頸椎 (C1-C7)**：自然前凸曲度，負責頭部前傾與仰俯。
  * **胸椎 (T1-T12)**：後凸曲度，精確雕刻向後下傾斜的**棘突 (Spinous Process)** 與橫突。
  * **腰椎 (L1-L5)**：自然前凸 S 型曲線，平滑串聯骨盆與胸腔。
* **胸廓系統 (Thoracic Cage)**：
  * **12 對肋骨**：精確咬合於 12 節胸椎，呈現向後開展、向下向前包覆的立體弧度。
  * **真肋 (1-7 對)** 與 **胸骨 (胸骨柄、胸骨體、劍突)** 形成封閉閉環。
  * **假肋 (8-10 對)** 向上匯入形成真實的**倒 V 字型肋弓 (Infrasternal Angle)**。
  * **浮肋 (11-12 對)** 側向游離。
* **肩帶與上肢 (Shoulder Girdle & Upper Limbs)**：
  * **鎖骨 (Clavicle)**：內端咬合於胸骨柄 (胸鎖關節 SC Joint)，呈現立體 S 型雙曲度。
  * **肩胛骨 (Scapula)**：貼合於背側肋骨後壁 (T2-T7 高度)。
  * **肩胛岡 (Spine of Scapula)**：顯著橫貫背部形成銳利骨脊，外端膨大為**肩峰 (Acromion)**。
  * **肱骨 (Humerus)**：大臂骨，嵌入關節盂內，具備自然提攜角與防穿模保護。
* **骨盆系統 (Pelvic Girdle)**：
  * **薦骨 (Sacrum)** 與 **尾骨 (Coccyx)**：5 節癒合倒三角中軸骨，做為脊椎底座。
  * **髂骨 (Ilium)**：大扇形骨翼，頂部為**髂嵴 (Iliac Crest)**，前側為關鍵骨點**髂前上棘 (ASIS)**。
  * **坐骨 (Ischium)**：後下方承重基底，具備**坐骨粗隆**。
  * **恥骨 (Pubis)**：前下方骨架，中央以**恥骨聯合 (Pubic Symphysis)** 閉合。
  * **閉孔 (Obturator Foramen)** 與 **髖臼 (Acetabulum)**。

### 2. 藝用解剖運動學約束 (Kinematics)
* **對稱扭轉對抗 (Contrapposto)**：骨盆側傾與胸廓側傾反向時，腰椎自動呈現平滑 S 曲度。
* **肩肱節律 (Scapulohumeral Rhythm)**：肱骨抬起外展時，微幅連動鎖骨與肩胛骨上旋。
* **防穿模約束**：限制內收角，物理防止手臂骨頭穿刺進肋骨胸腔。

### 3. 繪師工作台介面 (UI/UX)
* **雙區塊獨立並排顯示 (Side-by-Side Split View)**：左側參考圖片、右側 3D 骨架，視線完全不遮擋。
* **360° 自由旋轉檢視**：滑鼠拖曳旋轉、滾輪縮放、平移。
* **快捷視角按鈕**：正視圖、側視圖 (看 S 曲度)、後視圖 (看肩胛岡與脊椎棘突)、俯視圖、重設。
* **2D 姿態特徵線**：在原圖上畫出雙肩軸、骨盆盆腔線、手臂骨線與脊椎動勢線。
* **獨立部位開關**：胸廓、鎖骨與肩胛骨、大臂肱骨、骨盆系統、關鍵骨點。
* **姿態微調滑桿**：胸廓俯仰/轉向/側傾、骨盆傾斜、腰椎側彎/曲度、雙臂外展。

## 🚀 快速啟動 (Getting Started)

### 本地運行
本系統採用純前端 WebGL (Three.js) 與瀏覽器端 MediaPipe AI 運行，無需複雜安裝：

1. 雙擊執行目錄下的 `start_server.bat`，或在命令列執行：
   ```bash
   python -m http.server 8080
   ```
2. 在瀏覽器中開啟：
   ```
   http://localhost:8080
   ```
3. 上傳任何真人模特兒照片，系統將自動解析姿態並即時連動 3D 骨骼！
